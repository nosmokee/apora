# Проверка обновления 0.7

- 60 автоматических проверок Chromium: 268 карточек, 36 тем сочинений, все десять расширенных пересказов, вопросы всех восьми авторов и десяти произведений, открытие ответов, навигация, API-перевод с подменой ответов, ошибка сети, лимит сервиса, многобайтовый текст, шесть числовых моделей, проверка входных данных, существующий словарный разбор русского языка офлайн, конструктор сочинения, сохранность избранного, ширина мобильного экрана.
- 7 проверок PWA: ограниченный набор из четырёх кешируемых файлов, единственная копия HTML, отсутствие дубля корневой страницы, очистка старого кеша без удаления избранного и текущей офлайн-копии, чтение литературы и открытие страницы с query-параметром без сети.
- Реальный MyMemory-запрос из браузера для публичной тестовой фразы прошёл. Это не гарантия доступности внешнего сервиса в любой сети и не проверка точности всех переводов.
- Мобильные скриншоты просмотрены. Нативные APK/EXE не собраны: нет SDK и исходного ключа Android. Java-мост проверен только чтением исходника, а не запуском на телефоне.

Рост кеша Android без измерений на устройстве не диагностирован. В исходном Service Worker обнаружено двойное сохранение одного примерно 14-МиБ HTML по двум адресам; это относится к веб/PWA, не объясняет автоматически кеш нативного APK. Обновление исключает этот дубль. Android WebView может хранить собственные временные данные даже при отключённом HTTP-кеше.
