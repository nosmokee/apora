## Опора 0.8.1 — Сделано NoSmoke

### Скачать
- **Windows 10/11 x64:** `Opora-0.8.1-Windows-x64.exe` — portable. Закройте старую «Опору» перед запуском новой. Нет доверенной цифровой подписи издателя; Windows может показать предупреждение.
- **Android 8+:** `Opora-0.8.1-Android.apk` — release APK с новым ключом подписи и отдельным ID `ru.opora.study.next`. Устанавливается **рядом с 0.6**, не обновляет её поверх и не требует удаления старой версии. На телефоне имя — «Опора». Данные старого APK и сайта автоматически не переносятся. Для будущих выпусков этого ID ключ сохранён в защищённых GitHub Actions secrets.
- **iPhone/iPad:** `Opora-0.8.1-iPhone-PWA.zip` — архив сайта, **не IPA**. Установка: https://nosmokee.github.io/opora/ → Safari → Поделиться → На экран Домой. Сам ZIP на iPhone приложение не устанавливает.
- **Браузер/компьютер:** `Opora-0.8.1.html` — автономный HTML.
- `SHA256SUMS.txt` — контрольные суммы файлов. `Android-signing-certificate.pem` — только публичный сертификат APK, не закрытый ключ.

### Что нового относительно 0.6
- ДЗ: локальные заметки, предметы, сроки, редактирование, поиск, выполненные задания, резервная копия и экспорт события в календарь.
- Перевод EN → RU внутри приложения через MyMemory. Интернет обязателен, текст отправляется стороннему сервису по кнопке. До 1500 символов за раз, есть внешние лимиты. Не вводите конфиденциальные данные.
- 10 расширенных пересказов, 78 тренировочных вопросов с ответами, 26 разобранных заданий по английскому, обществознанию, информатике и географии, 36 тем сочинений, 6 дополнительных числовых моделей.
- ДЗ — последний пункт меню на Windows и крайняя правая вкладка на телефоне. Подпись «Сделано NoSmoke».
- Устранён дубль большого HTML в PWA-кеше; очистка старого кеша не удаляет ДЗ и избранное.

### Ограничения и проверки
Напоминания «Опоры» срабатывают при открытом приложении или при следующем открытии. Фоновые напоминания без запущенного приложения не реализованы. Для этого импортируйте .ics в поддерживаемый календарь, подтвердите импорт и проверьте уведомление; если iPhone не предлагает импорт — создайте событие вручную.

Записи хранятся только на устройстве, не синхронизируются. Перед очисткой данных скачайте резервную копию ДЗ.

93 веб-проверки пройдены. CI проверяет запуск Windows-оболочки, загрузку интерфейса и сохранение ДЗ; Android — сборку, подпись и метаданные пакета. Ручной проверки на реальных Windows/Android/iPhone не проводилось.
