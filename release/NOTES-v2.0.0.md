# Опора 2.0

Создано NoSmoke · Telegram: https://t.me/nosmokke

- Расписание: предмет, день, время, кабинет, заметка; проверка пересечений, избранное и резервная копия JSON.
- Фильтры избранного для материалов, литературы, сочинений, учебных маршрутов, экзаменационных заданий, ДЗ и расписания.
- 821 карточка: добавлены 60 тем истории и 69 материалов по другим предметам; теперь 66 исторических тем. Это расширенная подборка для 9–11 классов, не исчерпывающая программа всех учебников.
- В десяти литературных произведениях добавлены даты создания и публикации, 72 блока по главам/частям и 80 вопросов с ответами; теперь минимум 12 вопросов в каждой карточке произведения.
- Два полных произведения общественного достояния: «Капитанская дочка» и «Евгений Онегин». Офлайн-читалка с главами, условными страницами приложения и закладкой. Приложения и незавершённые фрагменты подписаны отдельно. Страницы не совпадают с печатными изданиями.
- Учебные маршруты: выбор предмета и класса, затем темы с разборами. Это авторские материалы, не копии учебников. Для точного оглавления конкретного учебника нужны авторы, название и год издания.
- Сохранены 436 тем сочинений / 872 учебных образца, авторский банк ОГЭ/ЕГЭ и типовые офлайн-решатели. Не официальный банк ФИПИ и не универсальный ИИ.
- Онлайн-перевод удалён. Android: EN ↔ RU через Google ML Kit без сети после явного скачивания пакета. Windows/iPhone/HTML: машинного перевода в этой версии нет; исправление пробелов у знаков работает локально. Смысловые запятые и грамматика автоматически не восстанавливаются.
- Модули расписания, навигации, хранения и читалки вынесены в отдельные читаемые файлы; сборка воспроизводима.

## Установка и данные
Android: версия 2.0.0, versionCode 21, прежний ID ru.opora.study.next и постоянная подпись. Устанавливайте поверх совместимой версии, не удаляйте приложение; сначала экспортируйте важные ДЗ и расписание. Старая 0.6 с другим ID не обновляется этим APK.
Windows: закройте старый процесс перед запуском EXE. Доверенной подписи издателя нет.
iPhone: https://nosmokee.github.io/opora/ — откройте с интернетом, дождитесь «Офлайн готов», закройте и откройте установленную PWA. Не очищайте данные сайта. ZIP — для размещения сайта, не IPA.

ДЗ, расписание и закладки локальные, без синхронизации. Напоминания ДЗ не гарантированы при закрытом приложении; расписание не создаёт фоновые уведомления.


### Упрощение меню
Персонализация удалена. На телефоне снизу: Предметы, Книги, Тексты, Перевод, Ещё, ДЗ. Остальные разделы доступны в «Ещё» с поиском. Дублирующие кнопки над предметами убраны. Тема переключается прежней кнопкой солнца/луны. Android versionCode 21, версия приложения и файлы релиза остаются 2.0.0.
