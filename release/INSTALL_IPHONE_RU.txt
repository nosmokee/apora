ОПОРА 2.0.0 НА IPHONE / IPAD

1. Откройте https://nosmokee.github.io/opora/ в Safari с интернетом.
2. Дождитесь «Офлайн готов».
3. Поделиться → На экран Домой → Добавить.
4. Первый запуск с иконки выполните с интернетом; затем материалы доступны офлайн.
5. Внизу должна отображаться версия 2.0.0. Если открыта старая версия, закройте PWA и снова откройте с интернетом. Не удаляйте PWA и не очищайте данные сайта без резервной копии.

Это PWA, не нативный IPA. ZIP нужен для размещения сайта; открыть ZIP в «Файлах» недостаточно для установки.
Онлайн-перевод удалён. Офлайн-перевод EN ↔ RU доступен только в Android APK после загрузки модели; на iPhone и Windows машинный перевод в этой версии недоступен. Материалы, две полные книги, расписание, ДЗ и исправление пробелов работают без сети. ДЗ хранится локально на устройстве, между устройствами не синхронизируется.
Напоминания внутри приложения не гарантируются в закрытой PWA. Для фона используйте календарь и проверьте настройки уведомлений.

Если размещаете сайт сами: загрузите все файлы архива на HTTPS-сайт и откройте index.html. Не удаляйте лицензии.
