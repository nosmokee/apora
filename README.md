# Опора · 1.0.0 — исходники обновления

Учебная полка. Сделано NoSmoke.

## Исправление кнопки темы (без смены версии)

Восстановлена SVG-луна: исправлен повреждённый путь. В светлой теме кнопка показывает луну (переход к тёмной), в тёмной — солнце. Убрана стандартная синяя подсветка касания; обратная связь использует цвет темы. Клавиатурный фокус сохранён. Android versionCode 13, прежние ID и подпись.

## Что нового в 1.0.0

- **436 тем сочинений:** 400 новых вопросительных формулировок на 50 тематических основах плюс 36 прежних тем. Каждая тема доступна для 10 и 11 класса.
- **872 полных учебных сочинения:** по два в каждой карточке, 450–540 слов без заголовка по счётчику приложения. Разные формулировки и варианты используют общий аргументный банк; полное отсутствие повторов фраз не заявляется. Это авторская учебная подборка, а не копия закрытого банка ФИПИ и не гарантия всех возможных тем. Формат — рассуждение с литературной опорой, не задание 27 ЕГЭ по конкретному исходному тексту. Образцы предназначены для анализа, а не сдачи под своим именем.
- В «Текстах» появились направления и постраничная подгрузка; поиск работает также по полным текстам. План и сборщик собственного аргумента сохранены.
- **Биология:** 30 тем с 60 разобранными заданиями — во всех карточках есть ответы и шаги решения. Добавлены основные темы клеточной биологии, генетики, эволюции и экологии 10–11. Подборка не заменяет исчерпывающий учебник по конкретному УМК.
- **5 расчётных моделей биологии:** состав ДНК, длина ДНК, моногибридное скрещивание, передача энергии, равновесие Харди—Вайнберга. Указаны условия применимости и ограничения.
- **Перевод английский ↔ русский:** явный переключатель направления сохранён и проверяется. Android — офлайн после скачивания пакета Google ML Kit; iPhone PWA и Windows — MyMemory через интернет.
- Сохранены локальные ДЗ, экспорт, избранное, тема, имя приложения «Опора» и подпись Android. Новый versionCode 12; можно устанавливать поверх 0.8.1/0.9.x без удаления приложения. Перед обновлением рекомендуется резервная копия ДЗ.

Генерация учебного корпуса воспроизводима: `content/essay-bank-v1.json` + `tools/build_essays_v1.py`; биология — `tools/add_biology_v1.py`. В корпусе нет выдуманных прямых цитат. Общие литературные эпизоды намеренно используются в нескольких близких темах. Ориентир направлений: [ФИПИ](https://fipi.ru/itogovoe-sochinenie); официальные требования и тематику проверяйте у преподавателя.

## Перевод · новое в 0.9

- Переключатель английский → русский / русский → английский. Проверка явно неверного языка ввода и кнопка ⇄, которая переносит готовый перевод в поле ввода.
- **Android APK:** Google ML Kit (`com.google.mlkit:translate:17.0.3`), полноценный машинный перевод на устройстве. В переводчике нажмите «Скачать пакет»: около 30 МБ, по умолчанию Wi-Fi. Мобильная сеть — только по отдельному разрешению. После загрузки работает без сети, до 5000 символов.
- Перевод не запускает загрузку модели и не переключается на онлайн автоматически. Отсутствующий пакет/ошибка показаны явно. Есть проверка готовности и удаление пакета без удаления заметок. После удаления понадобится новая загрузка.
- **Windows, iPhone PWA и HTML:** перевод в обе стороны через MyMemory, нужен интернет. До 1500 символов, части до 450 байт. Для Android онлайн-режим выбирается отдельно.
- Офлайн-текст не отправляется сервису перевода. Google ML Kit может отправлять техническую диагностику: [описание данных SDK](https://developers.google.com/ml-kit/android-data-disclosure). Онлайн-текст получает MyMemory. История переводов не сохраняется.
- Автоматический перевод powered by Google Translate (ML Kit) может ошибаться; Google не гарантирует его точность, надёжность или пригодность для конкретной цели. [Условия и атрибуция](https://developers.google.com/ml-kit/language/translation/translation-terms).
- Имя установленного Android-приложения — **Опора**, без номера. ID и ключ версии 0.8.1 сохранены; новую APK можно ставить поверх 0.8.1 без удаления данных. Перед обновлением всё равно рекомендуется экспорт ДЗ.

## ДЗ · новое в 0.8

Вкладка «ДЗ»: локальные заметки по предметам, срок сдачи, редактирование, поиск, выполненные задания и время напоминания. При наступлении времени появляется баннер; при повторном открытии показываются пропущенные напоминания. Системные уведомления — только при поддержке браузера, разрешении пользователя и работающем приложении. Фоновый Web Push без сервера не реализован.

Для внешнего календаря доступен файл .ics с событием и VALARM. Импорт и разрешения уведомлений необходимо подтвердить в календаре; совместимость импорта на iPhone зависит от приложения. Если импорт не предлагается, создайте событие вручную. Резервные копии ДЗ — JSON, не публикуются и не отправляются на GitHub. Между устройствами синхронизации нет.

Сайт iPhone/PWA использует те же материалы, переводчик и ДЗ. Обновление HTML/Service Worker не очищает локальные записи. Не удаляйте установленную PWA и не очищайте данные сайта для обновления.

## Что изменено

- Онлайн-перевод EN ↔ RU внутри приложения через MyMemory. Нужен интернет. До 1500 символов за запрос пользователя; запрос делится на части до 450 байт. Сервис имеет собственные лимиты. История переводов в приложении не сохраняется. Не отправляйте конфиденциальные данные.
- Все 10 литературных пересказов расширены до восьми последовательных эпизодов. Добавлены 40 вопросов по произведениям, 32 — по восьми авторам, шесть — по общим литературным темам. Это тренировочные вопросы, не предсказание вопросов преподавателя.
- 26 разобранных заданий по всем имеющимся темам английского, обществознания, информатики и географии (без карточек атласа).
- Шесть офлайн-моделей для своих чисел: масштаб, естественный прирост, часовые пояса, реальная доходность, объём изображения, системы счисления.
- Ранее добавлены 24 темы сочинений; в 1.0.0 всего 436. Планы, аргументы и смысловые фрагменты; не готовые работы под любое экзаменационное условие.
- В PWA большой HTML больше не сохраняется дважды под адресами `/` и `/index.html`. Старые кеши удаляются при активации обновления.
- Кнопка очистки лишнего кеша в «О приложении». Android: HTTP-кеш WebView; PWA: старые кеши, текущая офлайн-копия остаётся. Избранное и тема не удаляются.

Всего 692 материала. Это не универсальный ИИ-решатель и не полная программа всех предметов.

## Готовые версии

Сборки публикуются в [Releases](https://github.com/nosmokee/apora/releases). Workflow `Build and publish installers` собирает Windows portable EXE, подписанный Android release APK, автономный HTML и архив PWA для iPhone; выпуск становится публичным только после успеха всех трёх сборок.

**Android:** исходный ключ подписи 0.6 недоступен. Выпуск 1.0.0 использует новый постоянный ключ и ID `ru.opora.study.next`; устанавливается рядом с 0.6 под именем «Опора». Старую версию удалять не требуется, её данные не переносятся автоматически. Закрытый ключ хранится только в защищённых Actions secrets и не входит в репозиторий, APK или релиз. Публичный сертификат прилагается к релизу.

**Windows:** EXE не имеет доверенной подписи издателя. Перед запуском новой версии закройте старую.

**iPhone:** это PWA, не IPA; установка через Safari с [сайта](https://nosmokee.github.io/opora/). ZIP предназначен для размещения сайта, а не для установки из «Файлов».

## Запуск и публикация

- На компьютере откройте `index.html`. Материалы и решатели работают офлайн, перевод требует сети.
- Для PWA разместите корневые `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png` на HTTPS-сайте. Новая версия устанавливается после получения нового Service Worker; закройте и откройте PWA с интернетом.
- Для сайта `nosmokee.github.io/opora/` замените именно файлы в репозитории **opora**. Репозиторий **apora** хранит платформенные исходники и сам по себе этот сайт не обновляет.

## Разработка

`web-source/` — канонические исходники. `python3 web-source/build.py` создаёт `web-source/index.html`. После сборки скопируйте HTML в корень, `windows/app/` и `android/app/src/main/assets/`; Service Worker — также в корень сайта. Лицензии существующих данных сохранены.

Android: проект Gradle для Android Studio, JDK 17, SDK 35. Разрешение INTERNET нужно для онлайн-перевода, загрузки модели и служебных обращений SDK ML Kit. JavaScript-мост не принимает произвольные URL: единственный онлайн-переводческий адрес моста — `https://api.mymemory.translated.net/get`. HTTPS-запросы самой WebView по-прежнему заблокированы. HTTP-кеш отключён; это не отключает сохранение избранного в DOM Storage.

Windows: `cd windows && npm ci && npm run build:win`. Сетевой фильтр разрешает только GET `/get` указанного переводческого сервиса; остальные сетевые запросы оболочки блокируются. В Windows текст отправляется MyMemory только при запросе перевода.

iPhone/iPad: это PWA, а не IPA; устанавливается через Safari → Поделиться → На экран Домой после размещения на HTTPS.

## Проверки

В среде с Node.js, Playwright и Chromium:

```sh
NODE_PATH=/data/node_modules node tests/test-opora-v07.cjs
NODE_PATH=/data/node_modules node tests/test-opora-v07-pwa.cjs
```

Путь к Chromium и каталогу скриншотов при необходимости измените под свою среду. Основной сценарий использует подменённые ответы API для проверки ошибок, лимитов и деления текста. PWA-сценарий выполняет один реальный перевод тестовой фразы. Реальный ответ сервиса может отличаться.
