# Опора · 0.6

Офлайн-учебная полка. Создано Полянским Русланом · 12 ИСК.

## Скачать приложение

Готовые файлы — в [Releases](https://github.com/nosmokee/apora/releases/tag/v0.6):

- **Windows 10/11 x64**: `Opora-0.6-Windows-x64.exe` — portable, без доверенной цифровой подписи издателя.
- **Android 8+**: `Opora-0.6-Android.apk` — подписанный APK, актуальный Android System WebView.
- **iPhone / iPad**: `Opora-0.6-iPhone-PWA.zip` — архив сайта, **не IPA и не установщик из «Файлов»**.
- **Браузер / компьютер**: `Opora-0.6.html` — отдельный офлайн HTML.

## Установка на iPhone

Откройте **https://nosmokee.github.io/opora/** в Safari, дождитесь «Офлайн готов», затем **Поделиться → На экран Домой**. Первый запуск с иконки выполните онлайн. Затем доступна офлайн-работа. Внешним ссылкам нужна сеть.

## Структура

- Корень — готовый PWA-сайт: HTML, Service Worker, manifest и иконки.
- `web-source/` — JavaScript, стили, учебные данные, словарь, карты, лицензии и Python-сборщик. Сборка: `python3 web-source/build.py`.
- `windows/` — Electron-оболочка и встроенный HTML. Сборка: `cd windows && npm ci && npm run build:win` (Node.js и поддерживаемая среда сборки Electron).
- `android/` — исходники WebView-оболочки, встроенный HTML и конфигурация Android Studio. Смотрите ограничения сборки в `android/README.md`.
- `ios/` — инструкции PWA, без нативного проекта iOS.
- `tests/` — сценарии проверок веб-версии из среды разработки; пути и зависимости нужно настроить под свою среду.

HTML-копии в платформенных папках — снимки версии 0.6; Python-сборщик обновляет только web-source/index.html. После изменений синхронизируйте веб- и платформенные версии вручную.

## Возможности и ограничения

244 материала, алгебра и геометрия, калькулятор, числовые модели с формулами, задания по русскому по темам, словарь, история и учебные карты. Это конечная подборка, не универсальное ИИ-решение любых задач. Пунктуационные модели требуют самостоятельно выделить части предложения и выбрать условия.

Веб-версия проверена автоматическими и визуальными тестами. Пакеты EXE и APK собраны и проверены на целостность; запуск на настоящих Windows/Android/iPhone здесь не проверялся.
