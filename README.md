# Опора · 2.0

Офлайн-учебная полка для Android, Windows и iPhone PWA. **Создано NoSmoke** · [Telegram](https://t.me/nosmokke).

[Скачать 2.0](https://github.com/nosmokee/apora/releases/tag/v2.0.0) · [Открыть PWA](https://nosmokee.github.io/opora/)

## Возможности и границы

- **821 карточка**, включая 66 тем истории; в 2.0 добавлены 60 исторических и 69 других учебных материалов. Это авторская подборка для 9–11, не полная программа каждого УМК.
- Десять литературных разборов: создание и публикация, главы/части, минимум 12 вопросов с ответами на произведение. Группы глав подписаны диапазонами; разбор не подменяет чтение оригинала.
- Оригинальные тексты «Капитанской дочки» и «Евгения Онегина»: главы, закладки, условные страницы приложения. Общественное достояние; источник и примечания об изданиях — в [CLASSICS_LICENSE.md](CLASSICS_LICENSE.md).
- **436 тем / 872 учебных сочинения** по 350+ слов. Близкие темы используют общий аргументный банк. Не официальные образцы задания 27 ЕГЭ и не работы для сдачи под своим именем.
- Авторские задания ОГЭ/ЕГЭ с разборами, типовые офлайн-решатели, калькуляторы. Не официальный банк ФИПИ и не универсальный ИИ.
- Учебные маршруты по предмету и классу с поиском и избранным. Это не сканы и не полные копии учебников. Для оглавления и страниц конкретного учебника нужны название, авторы и издание; защищённые книги целиком не распространяются.
- ДЗ и расписание: локальные записи, избранное, редактирование и резервные копии JSON. Проверка пересечений уроков. Без облачной синхронизации; фоновые уведомления расписания отсутствуют. Напоминания ДЗ требуют работающего приложения либо внешнего календаря.
- Персонализация: тема, размер/форма кнопок, размер текста, цветовые обои или своё локальное фото. Сброс оформления не удаляет записи.
- Перевод EN ↔ RU **только Android, офлайн после скачивания Google ML Kit пакета**. Нет автоматической загрузки или онлайн-подмены. Google SDK может передавать служебную диагностику согласно своим правилам. На Windows/iPhone/HTML машинного перевода в этой версии нет. Онлайн-сервис удалён. Исправление пробелов у пунктуации работает локально, но не определяет смысловые запятые и грамматику.

## Установка

Готовые файлы публикуются в [Releases](https://github.com/nosmokee/apora/releases). Новый выпуск публикуется после успешных Windows/Android/web проверок и испытания настоящей языковой модели в Android-эмуляторе с отключённой сетью.

- **Android:** версия 2.0.0 / code 20, ID `ru.opora.study.next`, постоянный ключ прежних выпусков начиная с 0.8.1. Устанавливайте поверх, не удаляя приложение. Перед обновлением экспортируйте важные данные. Старая 0.6 с другим ID устанавливается отдельно, данные автоматически не мигрируют. Закрытый ключ только в Actions secrets, публичный сертификат прилагается.
- **Windows:** portable EXE. Закройте прежний процесс перед запуском. Доверенной подписи издателя нет.
- **iPhone:** [PWA](https://nosmokee.github.io/opora/), Safari → Поделиться → На экран Домой. Первый запуск с интернетом до «Офлайн готов». ZIP для хостинга, не IPA. Для обновления закройте/откройте PWA с сетью, не очищайте данные сайта.

## Архитектура

- `web-source/library.json` — основной корпус; `data/*-v2.json` — дополнительные оригинальные материалы; `data/classics.json` — полные публично-доступные классические произведения.
- `web-source/modules/` — хранение, расписание, оформление, читалка, учебные маршруты, сведения о приложении и интеграция. Предыдущие предметные модули сохранены для совместимости.
- `web-source/build.py` — воспроизводимая автономная сборка без сети. Корневой `index.html` и платформенные копии — сгенерированный дистрибутив, вручную их не редактируют.
- `android/` — WebView-оболочка и нативный ML Kit; `windows/` — Electron-оболочка с запретом сетевых запросов из страницы.
- `tools/import_classics.py` — отдельный импорт с атрибуцией; обычная сборка ничего не скачивает.
- `web-source/sw.js` — четыре ограниченных офлайн-ресурса, одна копия HTML; старые кеши очищаются, локальные записи не затрагиваются.

## Сборка и проверки

```sh
python3 web-source/build.py
# Синхронизировать index.html, sw.js, manifest.webmanifest и обе иконки
# из web-source/ в корень, windows/app/ и android/app/src/main/assets/.
python3 tests/test-icons.py
# Нужны Node 24 и playwright. OPORA_CHROMIUM задаёт путь к Chromium.
node tests/test-opora-v2.cjs
node tests/test-opora-v2-pwa.cjs
node tests/test-offline-exams.cjs
node tests/test-button-spacing.cjs
cd windows && npm ci && npm run test:smoke && npm run build:win
# Android: Java 17, Gradle 8.11.1, SDK 35; ключ берётся только из защищённого окружения.
```

Workflow `release-v2.yml` собирает v2.0.0; автоматически публикует только после всех проверок и добавляет SHA256. Репозиторий **apora** — исходники/релизы; отдельный **opora** содержит пять файлов сайта GitHub Pages.

[Изменения 2.0](release/NOTES-v2.0.0.md). Лицензии сторонних словарей/справочников сохранены рядом с исходниками и в архиве PWA.
