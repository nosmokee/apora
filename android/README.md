# Android

Исходники нативной WebView-оболочки и встроенный офлайн HTML.
Открыть эту папку в Android Studio с JDK 17 и Android SDK 35, выполнить Gradle Sync и Build APK. Gradle wrapper не включён; Android Studio может предложить настройку Gradle 8.11.1.

Опубликованный APK 0.6 собран напрямую инструментами Android SDK и ECJ, не этим новым Gradle-проектом. Gradle-конфигурация подготовлена для дальнейшей разработки, но отдельно здесь не проверялась.
Ключ подписи релизного APK НЕ опубликован. Для обновления установленного релиза нужен исходный ключ; иначе следует удалить старое приложение или использовать другой applicationId.
Android 8+, актуальный Android System WebView. Проверки на реальном устройстве не проводились.

Обновление 0.8: локальное ДЗ и экспорт JSON/ICS через системное сохранение файла, подпись NoSmoke. INTERNET разрешён для фиксированного HTTPS-сервиса перевода. Фоновых напоминаний Android пока нет; используются напоминания при открытом приложении или внешний календарь. APK 0.8 не собран.
