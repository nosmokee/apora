# Android 0.8.1

JDK 17, Gradle 8.11.1, Android SDK 35 / Build Tools 35.0.0, Android 8+.

Сборка: `gradle -p android assembleRelease`. Для подписи задайте OPORA_KEYSTORE_PATH и OPORA_KEYSTORE_PASSWORD; alias opora-next. Без них локальная release-сборка будет неподписанной. Ключи не коммитить.

На GitHub Actions ключ восстанавливается из защищённых secrets, используется для сборки и удаляется с runner. Открытый сертификат, но не закрытый ключ, включён в релиз.

Ключ подписи 0.6 недоступен: новый APK имеет ID `ru.opora.study.next`, устанавливается рядом с 0.6 и не переносит её данные. Не удаляйте старую версию ради установки новой. Последующие версии этого ID должны использовать тот же новый ключ.

Фонового планировщика напоминаний нет. Поддерживаются баннеры при открытом приложении/следующем запуске и экспорт ICS для внешнего календаря. Интернет требуется только переводчику; HTML и учебная база встроены.
