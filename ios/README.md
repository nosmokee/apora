# iPhone / iPad

Это PWA, а не нативный iOS-проект и не IPA. Файлы сайта находятся в корне репозитория.
Рабочая ссылка: https://nosmokee.github.io/opora/
В Safari дождаться «Офлайн готов», затем Поделиться → На экран Домой. Первый запуск с иконки выполнить онлайн.
Нативная подписанная IPA не создавалась. Проверки на физическом iPhone не проводились.
